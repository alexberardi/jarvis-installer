Install Jarvis

Your personal voice assistant. Private, self-hosted, and open source.

Jarvis runs as one program, jarvisd: no Docker, no database to set up. Pick your OS, run one command, and open the link it prints.

Install

Linux and macOS

In a terminal. It asks for sudo.

curl -fsSLo install.sh https://github.com/alexberardi/jarvis-server/releases/latest/download/install.sh && sh install.sh

Prefer to read it first? Run the curl part on its own, open install.sh, then sh install.sh. Options: sh install.sh --help (for example --user on Linux for a per-user service without root).

Windows

In PowerShell, as Administrator (or it asks for elevation).

irm https://github.com/alexberardi/jarvis-server/releases/latest/download/install.ps1 | iex

The installer checks the download against the release's SHA256SUMS, registers jarvisd as a system service, checks that nodes and phones can reach it, and offers to open the firewall for your local network.

What happens next

  1. 1

    Open the setup link

    The installer prints a link like http://<server>:7710/setup#token=…. Lost it? sudo jarvisd setup-link prints it again.

  2. 2

    Run the setup wizard

    Create the first account, pick your hardware and a model. Nothing large is downloaded until you choose a model there.

  3. 3

    Chat, and connect nodes and the app

    The web app stays on port 7710: everyone in the household can chat with Jarvis there, and admins manage the server. Point nodes and the mobile app at http://<server>:7700; jarvisd also announces itself on your network.

Upgrading from the legacy Python stack?

jarvisd import-legacy copies your users, households, nodes (with their keys, so Pi nodes reconnect without re-provisioning), settings, memories and routines into a fresh jarvisd, before you run the setup wizard. It is a dry run unless you pass --apply, and it never changes the legacy database.

Read docs/install/legacy-import.md before you start. The installer's --stop-legacy option (-StopLegacy on Windows) stops the old containers but deletes nothing.
