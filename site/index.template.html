Download Jarvis Automation

Your personal voice assistant. Private, self-hosted, and open source.

Jarvis Automation runs Jarvis on a computer of yours: one server for the household, no Docker and no database to set up. Download the installer for your OS, run it, and open the setup page.

Pre-release. Jarvis Automation is in pre-release ({{tag}}): expect rough edges, and expect things to change between releases. Release notes

Download

Server

Install it once, on the computer that stays on (a desktop, a mini PC, a home server). It runs Jarvis for everyone in the household.

{{server_downloads}}

Agent

The desktop agent, for each person's own computer: talk to Jarvis there and let it work on that computer. It installs for you only, without administrator rights.

{{agent_downloads}}

macOS needs Apple silicon (Intel Macs are not supported); Windows needs amd64. A GPU is optional. Other files and older versions are on the Releases page.

Then open the setup page

  1. 1

    Open http://<host>:7710/setup

    <host> is the computer you installed the server on. The installer opens the page for you (or prints the link, on a computer without a screen). Lost it? sudo jarvisd setup-link prints it again.

  2. 2

    Run the setup wizard

    Create the first account, pick your hardware and a model. Nothing large is downloaded until you choose a model there.

  3. 3

    Chat, and connect the agent, nodes and the app

    The web app stays on port 7710: everyone in the household can chat with Jarvis there, and admins manage the server. {{apps}}

Migrating from the old Docker install?

The Docker (microservice) install is retired for new installs: it no longer installs out of the box. Its docs stay, frozen, in the Legacy section of the documentation. Moving your users, nodes, settings and memories to Jarvis Automation is described in Migrating from the old Docker install.
